# Трекер курения

Простое веб-приложение для отслеживания выкуренных сигарет. Позволяет отмечать каждую сигарету, видеть статистику за сегодня и историю по дням.

## Возможности

* **Учет**: Большая кнопка "Я покурил" для быстрой записи.
* **Отмена**: Кнопка "-1" (undo), если нажали случайно.
* **Статистика**: Счетчик за сегодня и список по прошедшим дням.
* **Локализация**: Интерфейс полностью на русском языке.

## Быстрый запуск (Локально)

Вы можете запустить приложение на своем компьютере двумя способами.

### Способ 1: Использование Docker (Рекомендуется)

Если у вас установлен Docker, просто выполните команду в папке проекта:

```bash
docker compose up -d --build
```

Сайт будет доступен по адресу: http://localhost:5000

### Способ 2: Запуск через Python

Если вы хотите запустить без Docker:

1. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Запустите приложение:**
   ```bash
   python app.py
   ```

Сайт будет доступен по адресу: http://localhost:5000
